# SoMdMesh.org

You found our repo! Woot!

If you meant to find the website, please visit [somdmesh.org](www.somdmesh.org).

The goal is to provide information to help get folks started using Meshtastic (and soon other) mesh networks in and around the Southern Maryland area. As time goes by, I'll update this site with various projects, configurations, and more. If you would like to have an article or project featured, please reach out to somdmesh@gmail.com.

AI was used to build the website templates, but all content was written by me (Austin Steingrube).

The goal of the site is to provide information for a local community. That said, I do have Amazon affiliate links. Proceeds from these links go towards radio projects such as setting up nodes and capabilities for the communities.
