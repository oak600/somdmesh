The LongFast default channel on frequency slot 20 is also commonly used.

Note: The "LongFast" coding preset is being sunset in the US when Meshtastic Firmware 2.8 is released. This is due to a misunderstanding about FCC rule interpretations.

If you are in the area but cannot get any contacts, try LongTurbo on Slot 14 as a tentative alternative. It will take a while for folks to switch over and rebuild the network with the new settings, so be patient; the mesh is built by hobbyists and volunteers. The new settings also have less range, so more nodes will be needed to span distances.

A different way to stay connected

What is Meshtastic?

Meshtastic is an open-source project that allows users to stay connected without cellular service or internet. It's a great way to stay connected if normal comms break down and is a lot of fun day to day.

The network itself is formed by users in the community just having their radios on at home, at work, or while moving around the area.

All you need is a compatible radio which can be purchased on sites like Amazon and others. There are many different options to choose from based on your needs! We'll get the site updated with good options soon!

How Can I Help?

The easiest way to help is just to get a radio! Turn it on and keep it charged so the mesh network grows!

If you live in an area with few nodes, you might also consider putting up a client or client_base node high up in a tree or on a mast. This will help extend the mesh to the others around you!

Tech savvy? Add new capabilities to the mesh! Folks have made bulletin board systems (BBS), weather monitoring and alert services, and more all to help out the local community.

If you have another mesh network you'd like to have featured on the site, visit About Us and get in contact!
